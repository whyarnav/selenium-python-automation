# Selenium Python Automation Framework

## Project Overview
This project is a Selenium-based automation framework developed using Python to automate the login functionality of a web application.

## Tools & Technologies
- Python
- Selenium WebDriver
- ChromeDriver
- Page Object Model (POM)

## Test Scenarios Automated
- Valid login test
- Invalid login test

## Key Features
- Page Object Model for better code maintenance
- Explicit waits for stable execution
- Logging for execution tracking
- Positive and negative test scenarios

## How to Run the Project
1. Install Python
2. Install dependencies:
   pip install -r requirements.txt
3. Run the test:
   python tests/test_login.py

## Notes
This is a practice project built using a public demo website to demonstrate automation testing concepts.
